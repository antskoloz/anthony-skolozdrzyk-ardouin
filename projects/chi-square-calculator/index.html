How to read your results

A chi-square test compares the counts you observed with the counts you would expect if group and outcome were unrelated. The bigger the gap, the bigger χ², and the smaller the p-value: the probability of seeing differences this large if the groups were truly the same. Below your threshold (10%, 5% or 1% for 90, 95 or 99% confidence), the result is statistically significant.

Cramér's V tells you how strong the relationship is, from 0 to 1. With a lot of traffic even a trivial difference is "significant", so always read the effect size next to the p-value.

Methodology

Chi-square test of independence on an r × c table of counts:

E(i,j) = (row total i × column total j) / grand total χ² = Σ (O − E)² / E degrees of freedom = (r − 1)(c − 1) p-value = P(χ²(df) > observed χ²) Cramér's V = √( χ² / (N · min(r − 1, c − 1)) )

With the Yates correction (2×2 only), each |O − E| is reduced by 0.5 before squaring. Effect-size labels use Cohen's benchmarks scaled by the table size (for a 2×2 table: below 0.1 negligible, 0.1 small, 0.3 medium, 0.5 large).

For a 2×2 table without correction, χ² equals the square of the pooled two-proportion z statistic, so both tests give the same p-value.

Assumptions: each observation is counted once and belongs to exactly one cell, observations are independent (the same visitor should not appear twice), and expected counts are large enough: the usual rule is at least 5 in every cell. The calculator warns you when this is not the case. It does not correct for multiple comparisons or repeated looks at the data.

Frequently asked questions

What is a chi-square test used for in marketing?

It tests whether two categorical variables are related, for example whether conversion (yes or no) depends on which variant a visitor saw, or whether conversion differs across channels. It compares the counts you observed with the counts you would expect if there were no relationship.

Chi-square test or z-test for an A/B test?

For a simple control-versus-variant comparison of conversion rates they give the same p-value: the uncorrected 2×2 chi-square statistic equals the square of the two-proportion z statistic. Chi-square is more general because it also handles three or more groups or outcomes.

What does the p-value mean here?

It is the probability of seeing differences at least as large as yours if the groups were truly the same. If it is below your threshold (10%, 5% or 1% for 90, 95 or 99% confidence) the result is called statistically significant.

What if some expected counts are below 5?

The chi-square approximation becomes unreliable when expected counts are small. Collect more data, merge sparse categories, or use Fisher's exact test for a 2×2 table.

What is Cramér's V?

Cramér's V is an effect-size measure from 0 (no association) to 1 (perfect association). It tells you how strong a relationship is, which matters because a very large sample can make a tiny difference statistically significant.

If the test is significant, which group is different?

A significant chi-square test on a table with more than two groups only says that at least one group differs. Compare the row percentages, or run pairwise comparisons with an adjustment for multiple tests, to find where the difference is.
