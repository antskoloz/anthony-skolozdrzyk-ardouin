Import a Markdown post

Pick a .md file you already wrote (front matter + body, same shape as your other posts) and this opens GitHub's own "create file" screen — filename and content pre-filled where possible — so you commit it straight into src/content/blog/ without hunting for the folder yourself.

Read entirely in your browser — nothing is uploaded anywhere until you click "Commit changes" on GitHub's own page.

This becomes the post's URL. Use lowercase, hyphens, no spaces, and keep the .md ending.
